# 기획서 — 개포동공원 공영주차장 혼잡도 조회 페이지

## 0. 프로젝트 개요
코디세이 교육관 방문 시 주로 이용하는 **개포동공원 공영주차장(구)**은
인근 아파트·상가 수요로 만차가 잦다. 방문 전 "이 시간대에 자리가 있을까"를
미리 가늠하고, 가능하면 덜 붐비는 시간대를 추천받기 위한 1페이지 웹 도구를 만든다.
10분 단위로 수집한 주차 데이터(CSV)를 기반으로 하며, 인터넷 연결 시 최근 수집값도 함께 보여준다.

---

## 1. 대상 사용자
- 1차: **본인** (코디세이 교육관 방문 시 개포동공원 공영주차장 이용)
- 추후: 데이터가 충분히 쌓이면 공개 검토 (이번 범위 아님)

## 2. 사용 목적
- "**내가 가려는 시간대에 자리가 있을까?**"를 과거 데이터 기반 평균 혼잡도로 가늠
- "**지금 자리 있나?**"를 최근 수집값으로 확인
- 혼잡한 시간대를 피해 **덜 붐비는 방문 시간대를 추천**받기

## 3. 화면 구성과 동작
한 페이지(단일 HTML)로 구성하며, 위에서 아래로 3개 영역을 둔다.

### ① 현재 시간대 평균 혼잡도 그래프
- 페이지를 열면 **현재 요일·시간대**의 평균 주차가능면과 혼잡도 등급을 크게 표시한다.
- 아래에 **해당 요일의 하루 전체 시간대 평균 가능면**을 막대그래프(CSS 기반)로 보여주고,
  현재 시간대 막대를 강조한다.

### ② 방문 시간 조회 + 추천 시간대
- 사용자가 **요일과 시간을 선택**하면, 해당 시간대의 평균 가능면·혼잡도 등급을 표시한다.
- 선택한 시간대가 '혼잡' 또는 '매우 혼잡'이면, **같은 요일 안에서**
  평균 가능면이 많은 순으로 대체 시간대를 1·2·3순위로 추천한다.

### ③ 실시간 현황 버튼
- 버튼을 누르면 **가장 최근에 수집된 값**(수집시각·가능면·혼잡도)을 표시한다.
- 최근 수집값이 없거나 오래된 경우(갱신 지연 등) **"최근 데이터 없음/지연"**을 안내한다.
- 정확한 현재값 확인을 위해 **서울시 주차정보 페이지로 가는 바로가기 링크**를 함께 제공한다.

### 혼잡도 등급 기준 (주차가능면 기준)
| 주차가능면 | 혼잡도 |
|---|---|
| 30면 이상 | 여유 |
| 11 ~ 29면 | 양호 |
| 6 ~ 10면 | 혼잡 |
| 5면 이하 | 매우 혼잡 |

## 4. 필요한 자료
| 자료 | 내용 | 출처 / 권한 |
|---|---|---|
| 주차 데이터 | 10분 단위 수집 CSV (요일/시간/총면/가능면 등) | 서울시 주차정보안내시스템(parking.seoul.go.kr)의 detail.do 응답을 Python으로 수집. **비공식 요청**이며 개인 용도로만 사용 |
| 데이터 포함 방식 | 프로토타입용 2~3일치 데이터를 **HTML 내부 JS 배열**로 포함 | 자체 생성 |
| 실시간 링크 | 서울시 주차정보 페이지 URL | https://parking.seoul.go.kr/ |
| 글꼴 | 시스템 기본 글꼴 사용(외부 글꼴 미사용) | - |

> 수집에 사용하는 CSV 컬럼: `collected_at, code, name, capacity, cur_parking, available, source_time, lag_min, di_total, di_occupied`
> (웹페이지에는 이 중 요일·시간·available 중심으로 가공해 사용)

## 5. 완료 기준
- [ ] **다른 파일이나 로그인 없이** HTML 파일 하나를 더블클릭하면 브라우저에서 열린다.
- [ ] 페이지를 열면 ①영역에 현재 요일·시간대의 평균 혼잡도 등급과 막대그래프가 표시된다.
- [ ] ②에서 요일과 시간을 선택하면, 해당 시간대의 평균 가능면 수와 혼잡도 등급이 표시된다.
- [ ] ②에서 '혼잡/매우 혼잡'인 시간을 선택하면, 대체 추천 시간대가 1·2·3순위로 표시된다.
- [ ] ③의 실시간 현황 버튼을 누르면 최근 수집값(또는 "데이터 없음" 안내)과 서울시 페이지 링크가 표시된다.
- [ ] 인터넷이 연결되지 않아도 ①②와 CSS 그래프는 정상 동작한다.

## 6. 필수 기능 / 추가 기능
### 필수 기능
1. 내장 데이터 기반 **요일·시간대별 평균 혼잡도 계산 및 등급 표시**
2. 현재 시간대 평균 혼잡도 **막대그래프(CSS)**
3. **방문 시간 선택 → 혼잡도 표시**
4. **대체 방문 시간대 1·2·3순위 추천**
5. **실시간 현황 버튼**(최근 수집값 표시 + 서울시 페이지 링크)

### 추가 기능 (이번 구현 제외)
- Chart.js 등 외부 차트 라이브러리로 그래프 고도화 (CDN=인터넷 필요)
- CSV 파일을 fetch로 직접 읽어 데이터 자동 갱신 (별도 파일 필요)
- 브라우저에서 detail.do를 직접 호출한 **실시간 자동 조회** (CORS·서버 필요 가능성)
- 데이터 누적 공개 및 다중 사용자 지원
- 주차장 여러 곳 비교

> 로그인·API 키·서버가 필요한 기능과 챗봇·AI 기능은 이번 구현에서 제외한다.

## 7. 한계 및 비목표 (3가지)
1. **실시간 정확도 한계**: 표시값은 10분 단위 수집값·원천 갱신 지연으로 실제와 **5분 이상 차이**날 수 있으며, 수집이 멈춘 구간은 데이터가 없을 수 있다. 완전한 실시간을 보장하지 않는다.
2. **데이터 범위 한계(비목표)**: 프로토타입은 **2~3일치** 내장 데이터만 사용하므로, 요일·시간대 평균의 신뢰도가 낮고 요일별로 데이터가 없는 칸이 있을 수 있다. 장기 통계·예측은 목표가 아니다.
3. **대상·배포 한계(비목표)**: 개포동공원 공영주차장(구) **한 곳만** 다루며 본인 사용 목적이다. 데이터 출처가 비공식 요청이라 **외부 공개·배포는 하지 않는다**. 다른 주차장 지원은 목표가 아니다.

## 8. 검증 방법 (1가지)
- **비교 대상**: 페이지 ③에 표시된 '최근 수집값(가능면 수)' vs 서울시 주차정보 페이지의 실제 현황값
- **절차**:
  1. 페이지에서 실시간 현황 버튼을 눌러 표시된 최근 수집 가능면 수와 수집시각을 기록한다.
  2. 같은 시각 서울시 주차정보 페이지(개포동공원)에서 `잔여면 = 총면(capacity) - 현재주차대수(cur_parking)` 값을 확인한다.
  3. 두 값을 비교해 차이를 확인하고, 차이가 크면 수집시각(lag_min)으로 지연 여부를 점검한다.
- (혼잡도 등급 검증) 특정 시간대의 평균 가능면 수를 CSV에서 직접 평균 내어, 페이지가 표시한 등급이 4단계 기준표와 일치하는지 확인한다.
